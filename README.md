# Calmo

Ejercicios de respiración por la nariz para toda la familia (método Oxygen Advantage): sesiones guiadas, rutinas, calendario, progreso con logros, BOLT score y pasos sin respirar.

**App:** https://sergiohinojosa-mm.github.io/calmo/publicar/

| Carpeta | Qué tiene |
|---|---|
| `publicar/` | La app que sirve GitHub Pages. Sin datos de la familia: cada teléfono guarda los suyos. |
| `web/` | Código fuente de la app web (HTML, CSS y JavaScript, sin dependencias). |
| `backend/` | Servidor de Google Apps Script: usuario y contraseña, y datos en una hoja de Drive. |
| `docs/` | Historias de usuario y decisiones del producto. |
| `diseno/` | Diseño aprobado: las pantallas del lienzo de claude.ai. |
| `herramientas/` | `publicar.sh`: publica la app y respalda el proyecto en este repositorio. |
