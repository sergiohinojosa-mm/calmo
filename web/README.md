# Calmo

Ejercicios de respiración por la nariz para toda la familia: sesiones guiadas, rutinas, calendario, progreso con logros, BOLT score y pasos sin respirar.

- App web sin dependencias (HTML, CSS y JavaScript). Se publica tal cual con GitHub Pages.
- Los datos de cada familia no viven en este repositorio: se guardan en el teléfono y, con ingreso, en la hoja de Google Drive de quien administra la familia (ver `backend/`).

## Probarla en tu computadora

```bash
python3 serve.py
```

Luego abre la dirección que imprime, también desde un teléfono en la misma red WiFi.
